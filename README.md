# Drink for Meme – Chemistry Lab Simulation Game

A 3D first-person chemistry-themed simulation game where players mix humorous, meme-inspired “chemical” ingredients to create drinks, test reactions on a dummy NPC, complete orders, and progress through an XP-based ranking system.

Built as a team project using **Unity** and **C#**.

---

## ⭐ Key Features
- First-person lab environment with object interaction  
- Liquid pouring, mixing, and ingredient combination mechanics  
- “Dummy” tester NPC with unique reaction animations  
- Order system with hints, progression, XP, and ranks  
- In-game economy: shop, analyzer, currency system  
- Ingredient analysis device with time/cost mechanics  
- Save system, sound effects, settings menu  
- Meme-inspired humor throughout the game
